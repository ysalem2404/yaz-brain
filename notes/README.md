# notes/

Auto-generated notes from the [yaz-brain-ingest](https://github.com/ysalem2404/yaz-brain-ingest) pipeline.

Each `.md` file is one item from the Google Drive **AI Infographics** folder:
- Vision OCR extracted from the image
- LLM-generated title, TL;DR, category, tags, entities
- Perceptual hash for dedup
- Embeddings stored in `../public/data/embeddings.jsonl`

Layout:
```
notes/YYYY-MM/<date>-<slug>.md
```
Do not hand-edit — the ingester upserts by `id`.
