# Workflow and SQL Warehouse Cost Analytics

![Workflow and SQL Warehouse Cost Analytics](/img/notes/2026-10/workflow-and-sql-warehouse-cost-analytics.png)

## Summary

A benefits slide shows how workflow and SQL warehouse usage can be analyzed by use case, subscription, task, job, query, user, and warehouse to support cost/performance decisions.

## Key points

- Workflow views include workspace-level consumption, subscription summaries, task-level cost metrics, and top jobs by workflow.
- SQL warehouse usage can be tagged by use case to understand cost and compare cost-to-performance.
- Actionable measures include warehouse consumption and cost, query history and execution time, query counts by user/warehouse, queries per day, and price per query.
- The slide frames the output as better cost visibility and more actionable optimization insights.
