# Ultimate Tool Stack for AI Agents: 8 Categories, 24 Tools

![Infographic](public/img/notes/2026-05/ultimate-tool-stack-for-ai-agents.png)

## Summary
Ashish Sahu's "Ultimate Tool Stack for AI Agents" organizes 24 named tools into 8 categories arranged around a central AI hub: Agent Frameworks (LlamaIndex, CrewAI, LangChain), Distributed Agents (AutoGen, Dapr, AgentOps), Planning & Reasoning (LangGraph, Haystack, Semantic Kernel), Tool Execution (Python, Node.js, Postman), Memory & Knowledge (Weaviate, Pinecone, Milvus), Model Providers (Google Gemini, Anthropic, OpenAI), Monitoring & Debugging (LangSmith, Weights & Biases, PromptLayer), and Deployment & Scaling (Docker, Kubernetes, AWS). The wheel format is designed as a quick-reference map for assembling a complete agent stack from framework to deployment.

## Key points
- 8 categories arranged in a wheel: Agent Frameworks, Distributed Agents, Planning & Reasoning, Tool Execution, Memory & Knowledge, Model Providers, Monitoring & Debugging, Deployment & Scaling
- Agent Frameworks: LlamaIndex, CrewAI, LangChain
- Memory & Knowledge (vector DBs): Weaviate, Pinecone, Milvus
- Model Providers listed: Google Gemini, Anthropic, OpenAI (notably omits Ollama/local deployment)
- Monitoring & Debugging: LangSmith, Weights & Biases, PromptLayer
- Deployment & Scaling: Docker, Kubernetes, AWS — cloud/container-centric, no explicit on-prem or air-gapped option shown
