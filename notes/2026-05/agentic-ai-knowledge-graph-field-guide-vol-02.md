# The Agentic AI Knowledge Graph: Foundations, Retrieval Patterns, and the Frontier of Memory and Learning Loops

## Summary

A dependency-mapped 'Field Guide Vol. 02' by Brij Kishore Pandey organizing every major agentic AI concept into five tiers — Foundations (LLM reasoning, prompt patterns, tool use, embeddings, context windows), Retrieval & Memory (Classical/Graph/Agentic RAG, short/long-term/episodic memory), Agent Patterns (ReAct loop, planner-executor, multi-agent orchestration, context graph traversal, tool selection, reflection/self-critique), Production & Governance (confidence scoring, policy gates, audit trail design, decision reasoning logs, eval/observability, cost/token economics), and the Frontier (memory & learning loops, self-improving agents, multi-modal reasoning, agentic workflows at scale) — with a highlighted subset covered live in a May 20 webinar by Kognitos.

## Key Points

- Five-tier dependency structure: Foundations -> Retrieval & Memory -> Agent Patterns -> Production & Governance -> Frontier, with arrows showing what depends on what
- Foundations are explicitly labeled 'boring, non-negotiable — skip these and the rest collapses': LLM reasoning, prompt patterns, tool/function calling, embeddings, context windows
- Production & Governance tier: confidence scoring gates policy gates, which depend on audit trail design and decision reasoning logs — governance concepts positioned as prerequisites to frontier capabilities
- Frontier tier (hardest, most advanced): memory & learning loops, self-improving agents, multi-modal reasoning, agentic workflows at scale
- Core thesis: 'You cannot learn agentic AI top-down — you learn it by tracing the dependencies, and then watching one run end-to-end'

## Why Yaz Saved This

A uniquely structured dependency map (not just a list) of agentic AI concepts that shows how foundational, retrieval, pattern, and governance layers build toward frontier capabilities — valuable as a curriculum/roadmap reference for Yaz's own agentic AI learning plan and for structuring internal training content.
