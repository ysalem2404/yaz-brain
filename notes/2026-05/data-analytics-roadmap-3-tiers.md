# Data Analytics Roadmap: 3 Tiers from Excel to AI Tools

![Infographic](public/img/notes/2026-05/data-analytics-roadmap-3-tiers.png)

## Summary
A 3-tier learning roadmap for data analytics careers. Tier 1 (Foundations, beginner/most important): Excel → SQL — 'master these two and you can already get a job.' Tier 2 (Intermediate, automation/visualization): Power BI/Tableau ('best for Microsoft environments' / 'common in agencies and consultancies') → Python for automation and scale. Tier 3 (Advanced, portfolio/AI skills): GitHub for version control and visible portfolio → AI tools for prompt engineering, using AI to write/debug SQL/Python, and 'catching AI mistakes before they reach production.' Note: tiers don't need to be finished sequentially, 'but the order matters.'

## Key points
- Explicitly ranks Power BI as best for 'Microsoft environments' vs. Tableau for agencies/consultancies
- Advanced tier treats AI fluency (prompt engineering + catching AI mistakes) as a portfolio-level skill, not a beginner shortcut
- GitHub is framed as both version control and a public portfolio artifact
- Explicit sequencing philosophy: tiers can overlap, but foundational order should be respected
- Tier 1 alone (Excel + SQL) is claimed sufficient to be job-ready
