# 8 Claude Skills for Construction: From Contract Review to O&M Manual Building

## Summary

An eight-skill Claude use-case map tailored to construction/EPC workflows: Skill 1 Contract Reviews (clause-by-clause comparison, departures register with severity ratings — LD Cap, Consequential Loss, Notice Period, Liability); Skill 2 Project Context Builder/Indexer (scans project folders, creates a claude.md roadmap plus document/drawing summaries); Skill 3 Go/No-Go Bid Summary (analyzes bid docs, produces 5-slide summary + Excel Go/No-Go dashboard); Skill 4 Procurement Packaging (extracts requirements into package registers, scopes of work, pricing schedules); Skill 5 Estimate Reconciliation (checks estimate vs scope, calculation errors, gaps, double counts); Skill 6 Project Scheduling/Gantt (builds project schedules from packages); Skill 7 Document Controller/Auto (monitors correspondence, updates registers on a schedule); Skill 8 O&M Manual Builder (compiles specs/products/warranties into a standard O&M manual, flagging missing info).

## Key Points

- Skill 1's Departures Register example directly names EPC contract terms familiar to Yaz's field: LD Cap, Consequential Loss, Notice Period, Liability — each with severity ratings (High/Med)
- Skill 2 (Project Context Builder) explicitly creates a claude.md file as a 'roadmap for AI' with document/drawing/register summaries — directly mirrors the CLAUDE.md memory-layer concept seen in other saved infographics
- Skill 3 (Go/No-Go Bid Summary) produces a concrete 5-slide deliverable format: project overview, scope inclusions, scope exclusions, commercial terms, risks & watch-outs
- Skill 4 (Procurement Packaging) explicitly aligns pricing schedules to BOQ (Bill of Quantities) — an EPC-specific artifact
- Skill 7 (Document Controller) explicitly automates correspondence register updates on a daily/weekly schedule, reducing manual admin — directly applicable to EPC project controls

Extremely high relevance — this is a direct, EPC/construction-specific application of Claude skills covering contract review, bid go/no-go, procurement, scheduling, and O&M manuals, closely matching Yaz's own Bechtel EPC engineering context.
