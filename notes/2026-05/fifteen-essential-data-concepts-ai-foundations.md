# 15 Essential Data Concepts: Data Foundations AI Depends On

## Summary

Clare Kitching's fifteen-concept glossary covers the data foundations AI depends on: Ontology, Entity, Metadata, Physical Layer, Semantic Layer, Logical Layer, Data Virtualisation, Schema, Data Modelling, Vector Database, Data Pipeline, Orchestration, Data Quality, Observability, and Data Lineage — each paired with a plain definition and a note on how it specifically helps AI systems (e.g., vector databases 'enable richer retrieval and contextual understanding,' observability 'supports early detection of drift and unexpected behaviour').

## Key Points

- Ontology: shared definition of core business concepts and relationships, gives AI clear concepts to reason about
- Semantic Layer: business-friendly layer defining consistent metrics, ensures consistent definitions used by analysts, decision makers, and AI
- Vector Database: designed to search by similarity rather than exact matches, enables richer retrieval and contextual understanding
- Data Lineage: traces where data comes from, how it changes, and where it's used, provides transparency and explainability for AI outputs
- Observability: ability to see what data systems are doing and detect issues early, supports early detection of drift and unexpected behavior
- Each of the 15 concepts explicitly ties back to how it strengthens AI system reliability or capability
