# GaaS: Generative/Agentic AI as a Service — How It Works in 5 Steps

## Summary

A simple explainer defines GaaS (Generative/Agentic AI as a Service) as a shift from delivering static software to delivering AI agents that think, plan, and take action to complete work — illustrated with example agent tasks (find leads, write emails, schedule meetings, update CRM, track & analyze, deliver results) and a five-step 'how it works' flow: you give a goal in natural language, the agent thinks and plans, the agent uses tools and takes actions, the agent completes the work, and you get the outcome.

## Key Points

- GaaS reframes the value proposition from 'software you operate' to 'agents that operate on your behalf'
- Example agent tasks shown: find leads, write emails, schedule meetings, update CRM, track & analyze, deliver results
- 5-step flow: give a goal in natural language → agent thinks and plans → agent uses tools and takes action → agent completes work → you get the outcome
- Positions the AI as delivering outcomes directly rather than requiring the user to operate a tool

## Why Yaz Saved This

Simple framing of the 'AI as a Service' business model shift, useful shorthand when discussing agentic AI vendor positioning and procurement conversations.
