# Open-Source Toolbox for AI Development: Base Models to Specialized Libraries

## Summary

Brij Kishore Pandey's mind-map organizes the open-source AI development toolbox into nine categories radiating from a central hub: Base Models (Llama 3, Mistral, Gemma, Stable Diffusion, Whisper, LLaVA, FLUX.1), Model Deployment (Ollama, BentoML, Hugging Face Transformers, TorchServe), Vector Databases (Weaviate, Qdrant, PostgreSQL+pgvector), Graph Knowledge Bases (Neo4j, GraphRAG, Zep), Document Processing (Unstructured.io, Open Parse), Specialized Libraries (OpenCV, Background Remover, MindSQL), RAG Engines (Haystack, LlamaIndex), LLM Frameworks (Hugging Face Transformers, Semantic Kernel), AI Agentic Frameworks (CrewAI, AutoGen, Haystack Agents), Data Platforms & Processing (dbt, Apache Kafka, Apache Airflow), and Model Evaluation & Monitoring (Evidently AI, ClearML, Langfuse, Phoenix).

## Key Points

- Base Models category: Llama 3, Mistral, Gemma, Stable Diffusion, Whisper, LLaVA, FLUX.1
- Vector Databases: Weaviate, Qdrant, PostgreSQL+pgvector
- AI Agentic Frameworks: CrewAI, AutoGen, Haystack Agents
- Model Evaluation & Monitoring: Evidently AI, ClearML, Langfuse, Phoenix
- Data Platforms & Processing: dbt, Apache Kafka, Apache Airflow
- Organized as a single hub-and-spoke reference spanning the full open-source AI development lifecycle
