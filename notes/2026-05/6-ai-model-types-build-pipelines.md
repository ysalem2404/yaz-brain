# 6 AI Model Types and Their Build Pipelines

![Infographic](public/img/notes/2026-05/6-ai-model-types-build-pipelines.png)

## Summary
Breaks down 6 AI model types by their end-to-end build pipeline. Machine Learning Models: gather labeled data → clean/prepare → choose algorithm → train → check performance → adjust hyperparameters → predict on new data → track and improve. Deep Learning Models: collect large datasets → standardize inputs → create neural network → forward pass → calculate prediction error → backpropagate gradients → update weights → repeat → generate output. Generative Models: train using data → understand patterns → take user input → run through model → sample outputs → create new content → improve with feedback → produce final media. Hybrid Models: merge different models → train parts separately → build logic bridge → route input through pipeline → combine outputs → fix conflicts → provide final output. NLP Models: clean text → tokenize → convert to vectors → attention layers → feed into model → decode/classify → clean result → generate output text. Computer Vision Models: input image → resize/normalize → extract visual features → apply CNN layers → identify spatial patterns → classify/detect → refine results → output labels/boxes.

## Key points
- Each of the 6 model types gets an identical 8-9 step pipeline format, enabling direct side-by-side comparison
- Hybrid Models pipeline explicitly includes a 'fix conflicts' step — acknowledging that combining models produces disagreements to resolve
- NLP pipeline names 'attention layers' as a distinct pipeline stage between vectorization and model feeding
- Generative Models pipeline treats 'improve with feedback' as a step before final output, implying iterative refinement
- Computer Vision pipeline explicitly separates 'classify/detect' from 'refine results' as two distinct stages
