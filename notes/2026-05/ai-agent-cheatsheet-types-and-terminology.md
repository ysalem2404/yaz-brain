# AI Agent Cheatsheet: Types, Components, and Foundational ML Terms

![Infographic](public/img/notes/2026-05/ai-agent-cheatsheet-types-and-terminology.png)

## Summary
Ashish Joshi's "AI Agent Cheatsheet" is an introductory primer defining an agent as a system that "perceives environment and autonomously acts toward goals," learning and adapting over time. It breaks agents into five key components — Perception, Action, Environment, Goals, and Decision-Making — and a working diagram showing the human-control-to-autonomous-action spectrum, covering task delegation, memory, reactivity, internet/API access, and code interpretation. Five agent types are defined: Reactive, Model-Based, Goal-Based, Utility-Based, and Learning Agents. The sheet closes with foundational terminology (Reinforcement Learning, Supervised/Unsupervised Learning, Autonomy, Adaptation) and a toolset list (TensorFlow, PyTorch, Keras, Scikit-learn, OpenAI Gym).

## Key points
- Defines an agent as perceiving its environment and autonomously acting toward goals, with learning/adaptation over time
- Five key components: Perception, Action, Environment, Goals, Decision-Making
- Five agent types: Reactive, Model-Based, Goal-Based, Utility-Based, Learning Agents
- Working diagram spans human control through delegated autonomy, covering memory, reactivity, internet/API access, code interpretation
- Foundational ML terminology included: Reinforcement Learning, Supervised Learning, Unsupervised Learning
- Toolset list: TensorFlow, PyTorch, Keras, Scikit-learn, OpenAI Gym
