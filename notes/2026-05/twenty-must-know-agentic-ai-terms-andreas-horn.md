# 20 Must-Know Agentic AI Terms: The Production Vocabulary of Agentic AI

## Summary

Andreas Horn's twenty-term glossary defines the production vocabulary of agentic AI: MCP (the standard connecting agents to tools/systems/data), A2A (agent-to-agent communication protocol), Agent Loop (perceive-plan-act-observe), Tool Use, Orchestrator, Multi-Agent System, Memory, RAG, Grounding, Context Engineering, Guardrails, Policy Layer, Sandboxing, Human-in-the-Loop, Handoffs, Agent Observability, Agentic Pipeline, Evaluation (Evals), Agent Identity, and Agent Protocols (interoperability standards at scale).

## Key Points

- MCP: the standard that connects agents to tools, systems, and data
- A2A: a protocol for agents to communicate and coordinate with other agents
- Agent Loop: perceive, plan, act, and observe — the core loop of autonomous work
- Grounding: anchors outputs in trusted data to reduce hallucinations
- Context Engineering: designing the right context so agents understand what matters
- Guardrails: hard safety boundaries that prevent unauthorized or risky behavior
- Agent Identity: defines which agent acted, under which role, with which permissions
- Agent Protocols: standards that make agent ecosystems interoperable at scale
