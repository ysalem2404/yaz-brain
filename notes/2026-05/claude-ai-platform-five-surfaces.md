# Claude as an AI Platform: Chat, Code, Project, Skills, Cowork

![Infographic](public/img/notes/2026-05/claude-ai-platform-five-surfaces.png)

## Summary
Argues 'most leaders use Claude as a chatbot — use it as an AI platform,' breaking down five distinct Claude surfaces. Claude Chat: conversational assistant for drafting/brainstorming/research, workflow Prompt→ChatUI→Claude Models→Output. Claude Code: command-line autonomous coding agent for debugging/refactoring/building/testing across files, with file-system memory and multi-file editing. Claude Project: persistent workspace holding context/docs/instructions across conversations, for client work and team knowledge bases. Claude Skills: custom instruction sets that make Claude perform specific tasks consistently — standardized documents, repeatable reporting, team consistency. Claude Cowork: desktop app automating file management and cross-app repetitive workflows, extracting data from PDFs to sheets.

## Key points
- Core thesis: chatbot usage is underutilizing Claude — each surface targets a different production workflow
- Claude Code adds file-system memory and multi-file editing absent from plain chat
- Claude Skills is positioned as the consistency layer — same task, same quality, every time
- Claude Project's differentiator is persistent context across conversations, not one-off prompting
- Claude Cowork specifically targets bulk file operations and cross-app automation, not conversational tasks
