# Microsoft Copilot Cowork: From Conversation to Action

![Infographic](public/img/notes/2026-05/microsoft-copilot-cowork-conversation-to-action.png)

## Summary
Introduces Microsoft Copilot Cowork as 'your AI coworker for real work' that goes 'beyond chat' to delegate real tasks — 'organize my inbox, arrange my week, prep for a meeting, research a company.' Built on named agents (Cowork, App Builder, Researcher, Analyst, New agent) with native integrations into Microsoft 365, Fabric, Power BI, Dynamics 365, and ERP systems, plus third-party plugins/connectors (LSEG D&A, Miro Cowork, monday.com, S&P Global Energy). Key features: cross-device experience (desktop/iOS/Android with cloud-based execution continuing in background), Cowork Skills for reusable structured workflows, and native Microsoft 365 integration across Outlook (inbox/follow-ups), Teams (meeting coordination), Word (drafting/editing), Excel (data analysis/reports), Power BI (dashboards), and Dynamics 365 (sales/service/ERP). Available through the Frontier program.

## Key points
- Explicitly framed as beyond-chat delegation: 'move from ideas to action,' not just conversational assistance
- Cloud-based execution continues running even when the device is closed — persistent background task completion
- Native integrations span the full Microsoft stack: M365, Fabric, Power BI, Dynamics 365, plus named third-party connectors
- Cowork Skills enables reusable, consistent workflow automation, similar in spirit to Claude Skills
- Currently gated behind the Frontier early-access program, not general availability
