# How to Build an AI Agent: 8-Step Framework Plus Consumer/Agentic/No-Code Tool Comparison

## Summary

An 8-step framework for building an AI agent (define purpose & scope, system prompt design, choose LLM, tools & integrations, memory systems, orchestration, user interface, testing & evals) paired with a detailed comparison table across four tool categories: Consumer AI Agents (ChatGPT, Claude, Perplexity), Agentic Coding Tools (Cursor, Windsurf, Claude Code), No-Code Builders (Lindy, Relay.app, n8n), and Development Frameworks (LangGraph, CrewAI, LlamaIndex), each with LLM, deployment model, key features, and best-for use case.

## Key Points

- 8-step build framework: purpose/scope -> system prompt design -> choose LLM -> tools/integrations -> memory systems -> orchestration -> user interface -> testing/evals
- Memory systems breakdown: episodic (conversation), working memory, vector database, SQL/structured DB, file storage
- Consumer AI Agents comparison: ChatGPT (GPT-5, custom GPTs/DALL-E), Claude (Claude 4.5, projects/artifacts/200K context), Perplexity (search-first, citations)
- Agentic coding tools: Cursor (full IDE, multi-file editing), Windsurf/Codeium (flows, codebase awareness), Claude Code (terminal-native, autonomous coding)
- Development frameworks: LangGraph (graph-based, state management), CrewAI (role-based, 40+ integrations), LlamaIndex (RAG-first, data connectors)

## Why Yaz Saved This

A practical build framework combined with a current vendor/tool landscape comparison across consumer, coding, no-code, and framework tiers — useful reference for Yaz's own agent-development decisions and vendor evaluation work at Bechtel.
