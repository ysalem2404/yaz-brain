# 5-Layer Enterprise Agentic Tech Stack: Interface to Infrastructure

## Summary

Alok Sharan's five-layer stack maps the concrete tools behind major enterprise agentic AI projects: Interface Layer (chat UI, widget embeds, voice interface, API gateway; tools like Next.js, React, Streamlit, Gradio, FastAPI), Orchestration Layer (workflow engine, agent handoffs, multi-agent coordination; tools like LangGraph, AutoGen, CrewAI, Google ADK, Microsoft Semantic Kernel), LLM Layer (model routing, guardrails, observability; models like GPT-5, DeepSeek V3, Claude Opus, Llama 4, Gemini 2.5 Pro), Data Layer (vector database, RAG, knowledge graph; tools like Pinecone, Weaviate, Qdrant, Chroma, Neo4j), and Infrastructure Layer (compute GPU/TPU, CI/CD, security; tools like NVIDIA CUDA, Kubernetes, RunPod, Docker, Terraform).

## Key Points

- Interface Layer: chat UI, widget embeds, voice interface, browser extensions, Slack/Teams integration — built with Next.js, React, Streamlit, Gradio, FastAPI
- Orchestration Layer: workflow engine, agent handoffs, multi-agent coordination, memory management — built with LangGraph, AutoGen, CrewAI, Google ADK, Microsoft Semantic Kernel
- LLM Layer: model routing, guardrails, observability, bias detection, load balancing — spans GPT-5, DeepSeek V3, Claude Opus, Llama 4, Gemini 2.5 Pro
- Data Layer: vector database, embedding models, RAG, knowledge graph, data governance — Pinecone, Weaviate, Qdrant, Chroma, Neo4j
- Infrastructure Layer: compute (GPU/TPU), monitoring, security & compliance, container orchestration — NVIDIA CUDA, Kubernetes, RunPod, Docker, Terraform
