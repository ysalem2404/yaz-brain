# LLM vs RAG vs AI Agent vs Agentic AI: The Layers of Intelligence in AI Systems

## Summary

Clare Kitching's nested Venn/petal diagram illustrates how capabilities accumulate across four layers of AI system intelligence: LLM (instruction following, conversational memory, prompt engineering, chain-of-thought reasoning, transformer architecture), RAG (adds vector search, embedding models, custom knowledge base integration, hybrid search, source attribution), AI Agent (adds tool use/API calling, task decomposition, planning and execution, feedback loops, autonomous planning), and Agentic AI (adds multi-agent coordination, agent orchestration, A2A/MCP/ACP protocols, agent role assignment, long-term memory management). The overlapping regions show shared capabilities like context, reasoning, and semantic understanding that persist across all four layers.

## Key Points

- LLM layer: instruction following, conversational memory, prompt engineering, chain-of-thought, transformer architecture
- RAG layer adds: vector search, embedding models, custom knowledge base integration, hybrid dense-sparse search, source attribution
- AI Agent layer adds: tool use/API calling, task decomposition, planning & execution, feedback loops, autonomous planning
- Agentic AI layer adds: multi-agent coordination, orchestration, A2A/MCP/ACP protocols, agent role assignment, long-term memory management
- Shared core capabilities across all four layers: context, reasoning, semantic understanding
- Visualized as nested overlapping ellipses rather than a strict hierarchy, showing capability accumulation
