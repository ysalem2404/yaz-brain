# How to Use Copilot: Word, Excel, PowerPoint, and Chatbot Purpose/Features/Uses

## Summary

Aiswarya Venkitesh's mindmap details Copilot usage across four Microsoft surfaces: Copilot in Word (draft documents from a short prompt, rewrite/shorten text, summarize long files — pro tip: 'summarise this document into 5 bullet points'), Copilot in Excel (build charts/formulas/pivot tables from text, clean messy data, highlight trends — pro tip: ask 'what's driving this number?'), Copilot in PowerPoint (create full decks from text/Word docs, auto-generate speaker notes, turn dense text into visuals — pro tip: 'turn this report into a 7-slide summary with visuals'), and Copilot in Chatbot (search emails/files/chats instantly, draft replies/summaries, analyze PDFs/Excel/reports — pro tip: 'summarise everything I missed this week').

## Key Points

- Copilot in Word: draft documents from short prompts, rewrite/shorten text, summarize long files into key takeaways
- Copilot in Excel: build charts/formulas/pivot tables from text, clean messy data, highlight trends automatically
- Copilot in PowerPoint: create full decks from text or Word docs, auto-generate speaker notes, convert dense text to visuals
- Copilot in Chatbot: search across emails/files/chats instantly, draft replies and action notes, analyze PDFs/Excel/reports
- Each surface includes a specific 'pro tip' prompt example for immediate practical use
