# Create an Agent in Copilot Studio: 6-Step Walkthrough

## Summary

Microsoft's official six-step walkthrough for building an agent in Copilot Studio: go to Copilot Studio and sign in with a work/school account, start a new agent by describing what it should do, provide basic details (name, description, language, tone), add knowledge by connecting data sources (public website, OneDrive, SharePoint), test the agent in the test pane, and publish it to a defined audience. The example shown is an HR Assistant that answers questions about HR policies, benefits, and onboarding using SharePoint-connected knowledge.

## Key Points

- Step 1: Go to Copilot Studio, sign in with work/school account
- Step 2: Start a new agent by describing what it should do
- Step 3: Provide basic details — name, description, language, tone
- Step 4: Add knowledge — connect public website, OneDrive, or SharePoint data sources
- Step 5: Test the agent in the test pane and refine responses
- Step 6: Review and publish the agent to a defined audience (e.g., people in your organization)
- Example use case shown: HR Assistant answering policy/benefits/onboarding questions from SharePoint knowledge
