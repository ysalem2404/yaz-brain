# Modern System Design Technology Stack

![Infographic](/img/notes/2026-09/modern-system-design-technology-stack.png)

## Summary
A technology map groups a modern application stack into twelve layers, from user interface and traffic routing through data, messaging, deployment, and observability.

## Key points
- The front end uses frameworks such as React, Next.js, Angular, and Vue; gateway/reverse-proxy and load-balancing layers route incoming traffic.
- Backend services are built with runtimes/frameworks including Node.js, Spring Boot, .NET, FastAPI, and Go.
- Data layers cover relational and NoSQL stores, caching, messaging/event streaming, search/indexing, and object storage/content delivery.
- Containers and orchestration include Docker, Kubernetes, Amazon ECS, and OpenShift; monitoring spans Prometheus, Grafana, Datadog, OpenTelemetry, and New Relic.
