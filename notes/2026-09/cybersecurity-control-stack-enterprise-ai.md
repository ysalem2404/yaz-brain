# Cybersecurity Control Stack for Enterprise and AI

![Infographic](/img/notes/2026-09/cybersecurity-control-stack-enterprise-ai.png)

## Summary
A defense-in-depth map connects cyber-risk governance, protective controls, incident response, secure development, cloud and identity standards, and dedicated AI/agent security guidance.

## Key points
- The main operating flow is Govern and Identify, Protect, then Detect, Respond, and Recover, with NIST CSF 2.0, ISO/IEC 27001/27002, and NIST SP 800-61 Rev. 3 positioned across it.
- The controls column includes NIST SP 800-53, CIS Controls, ransomware readiness, application security, secure software development, cloud controls, post-quantum cryptography, digital identity, and zero trust.
- The AI-security lane names OWASP GenAI LLM Top 10, OWASP Agentic Top 10, and an Agent Control Standard as guidance for LLM application and agent-runtime risks.
- The stated goal is to govern cyber risk, reduce attack paths, detect and contain incidents, recover reliably, and secure AI-enabled systems.
