# Telemetry — Semantic Pipeline Network

## Summary
A telemetry pipeline turns raw logs into semantic logs enriched with cyber-threat intelligence, while retaining a raw bronze archive and a CTI snapshot context store.

## Key points
- Raw logs flow through a semantic transformer into semantic logs with CTI.
- A raw archive (bronze) preserves source telemetry.
- A CTI snapshot context store feeds the transformation path and telemetry is materialized separately.
