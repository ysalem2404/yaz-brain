# LLM, RAG, AI Agent and Agentic AI

![Infographic](/img/notes/2026-09/llm-rag-ai-agent-agentic-ai.png)

## Summary
A layered architecture comparison moves from direct LLM generation to retrieval-augmented generation, single-agent goal loops, and orchestrated multi-agent or workflow systems with shared state and replanning.

## Key points
- An LLM maps a prompt plus provided context to a generated response using learned parameters and sequential token generation.
- RAG adds a retriever and indexed knowledge: a query fetches relevant chunks, which are passed with the query to the LLM to produce a grounded response, though correctness is not guaranteed.
- An AI agent adds a goal, task state, instructions, decision, tool calls, observation, and repeated action until an outcome is reached.
- Agentic AI adds orchestration, multiple agents or workflows, shared task state, tools/data/environments, progress evaluation, and replanning toward an objective.
