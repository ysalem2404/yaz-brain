# The Self-Evolving Ontology

![Infographic](/img/notes/2026-09/self-evolving-ontology.png)

## Summary
A self-evolving ontology pattern lets agents use a grounded semantic structure, observe gaps in real workloads, propose small changes, evaluate them against the parent state, and update the ontology without losing control or relevance.

## Key points
- A static ontology becomes stale and misses emerging concepts; an evolving ontology learns from agent activity while staying grounded and lean.
- The loop is workload, trajectory observation, ontology update, and evaluation before a new state is adopted.
- Agents can use only the relevant slice of the ontology to solve real tasks, while execution trajectories reveal recurring gaps.
- Small semantic changes can produce real operational impact when candidate updates are compared with the parent ontology and evaluated.
