# The Modern AI Ecosystem — Tech Stack

## Summary

A dense map of the modern AI application stack, connecting foundation models and agent frameworks to RAG, embeddings, MCP servers and registries, vector databases, memory, observability, security, and workflow automation. It places tools such as LangChain, LangGraph, LlamaIndex, Google ADK, OpenAI Agents SDK, Amazon Bedrock Agents, Azure AI Foundry, Helicone, Arize Phoenix, LangSmith, Pinecone, Chroma, Redis, and Temporal across the stack.

## Key Points

- The diagram treats agentic AI as a composition of model, framework, context, tool, memory, and workflow layers rather than a single product.
- MCP is shown as a connective layer through filesystem, Drive, Slack, GitHub, PostgreSQL, and other servers, alongside an MCP registry and SDK.
- RAG and embeddings connect to multiple vector stores and retrieval tools, while observability and guardrails sit beside security, evaluation, and automation controls.

## Why Yaz Saved This

This is a useful index for spotting adjacent tools and for checking whether an agent architecture covers retrieval, tool access, memory, evaluation, observability, and governance.
