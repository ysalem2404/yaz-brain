# STIX Threat Intelligence Data Model

![Infographic](/img/notes/2026-09/stix-threat-intelligence-data-model.png)

## Summary
A threat-intelligence knowledge graph links STIX 2.1 objects such as indicators, malware, threat actors, campaigns, vulnerabilities, and courses of action to make cyber context machine-readable.

## Key points
- The example uses STIX 2.1 objects and relationships to represent threat intelligence.
- Indicators, malware, threat actors, campaigns, exploit targets, and courses of action are connected in one model.
- Structured relationships can preserve context around malicious activity and map it to attack lifecycle phases.
