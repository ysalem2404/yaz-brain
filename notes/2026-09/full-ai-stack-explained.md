# The Full AI Stack Explained

![Infographic](/img/notes/2026-09/full-ai-stack-explained.png)

## Summary
A visual map of the production AI stack spans model providers, embeddings, vector databases, parsing and ingestion, orchestration frameworks, and evaluation tools.

## Key points
- Model providers include Claude, Qwen, Gemini, Mistral, Llama, Cohere, OpenAI, and others.
- Retrieval infrastructure includes embedding models, vector stores such as Pinecone, PostgreSQL, Milvus, OpenSearch, Weaviate, Qdrant, and Chroma.
- The application layer includes document parsers, graph and agent orchestration, and frameworks such as LangChain, LlamaIndex, LangGraph, Haystack, and Together AI.
- Evaluation and monitoring tools such as Giskard, Ragas, DeepEval, and TruLens sit alongside the stack rather than being an afterthought.
