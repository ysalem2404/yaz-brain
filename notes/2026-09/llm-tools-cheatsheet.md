# LLM Tools Cheatsheet

![Infographic](/img/notes/2026-09/llm-tools-cheatsheet.png)

## TL;DR
A categorized map of the LLM tooling ecosystem, spanning model providers, agent systems, LLM application frameworks, vector databases, prompt tooling, and no-code or low-code builders.

## Key points
- Model providers shown include Claude, Gemini, Llama, Grok, DeepSeek, Cohere, Mistral, Qwen, and AI21 Labs.
- Agent and orchestration systems include AutoGen, CrewAI, Superagent, CAMEL-AI, MetaGPT, AgentVerse, and LangGraph.
- Application frameworks and development libraries include LangChain, LlamaIndex, Haystack, DSPy, Semantic Kernel, and OpenLLM.
- The map also groups vector stores such as FAISS, ChromaDB, Pinecone, Weaviate, Redis, and Qdrant, plus builders such as Flowise, Replit, Lovable, Chatbase, and Relevance AI.
