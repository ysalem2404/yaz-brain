# Vulnerabilities of AI Agent

![Infographic](/img/notes/2026-09/vulnerabilities-of-ai-agent.png)

## TL;DR
A threat map organizes AI-agent vulnerabilities around manipulation, impersonation, resource constraints, data poisoning, and systemic influence, pairing each risk with mitigation ideas.

## Key points
- Impersonation can exploit similar agent names, hijack communication channels, create trust-based manipulation, and enable unauthorized information extraction; suggested mitigations include advanced authentication and unique identifiers.
- Resource-exhaustion attacks target computational limits, degrade performance, and create denial-of-service conditions; dynamic allocation and intelligent throttling are suggested defenses.
- Data poisoning intentionally corrupts training data to introduce bias, unpredictable behavior, or backdoors; rigorous validation and continuous monitoring are proposed.
- Strategic manipulation can influence training data or generated responses at scale; comprehensive data-source verification and response validation are called out as mitigations.
