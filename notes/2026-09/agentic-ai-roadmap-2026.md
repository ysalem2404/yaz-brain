# Agentic AI Roadmap 2026

![Infographic](/img/notes/2026-09/agentic-ai-roadmap-2026.png)

## Summary
A staged learning roadmap moves from programming and prompting through agent basics, APIs, tools, orchestration, memory, RAG, deployment, evaluation, and security/governance.

## Key points
- The roadmap begins with programming and prompt skills, including Python/JavaScript, APIs, context management, task planning, and self-critique.
- Agent foundations cover autonomy levels, architecture, MCP and A2A, task decomposition, planning algorithms, decision policies, and action planning.
- Later layers add LLM APIs, function calling, external tools, retrieval, memory, agent frameworks, orchestration, vector stores, and RAG.
- Deployment, monitoring, evaluation, and governance are presented as essential end stages, with prompt-injection protection, API-key management, authentication, output filtering, and red-team testing.
