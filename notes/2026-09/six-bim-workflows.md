# 6 BIM Workflows

**TL;DR**
- Information requirements: establish purpose, define requirements, set the information need, and approve measurable deliverables.
- BIM execution planning: select BIM uses, map processes, assign responsibilities, and approve the BEP before production.
- Common data environment: work in progress, share for review, authorize and publish, then archive the record with version control and auditability.
- Model coordination: federate discipline models, run checks, assign issues, and verify resolution to reduce rework.
- OpenBIM exchange: define IDS rules, export IFC 4.3, validate the dataset, and exchange BCF issues for interoperable, traceable coordination.
- Asset information delivery: define asset needs, capture and verify asset data, verify handover, and update AIM/EAM for lifecycle insight.
