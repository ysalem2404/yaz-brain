# Types of APIs and Their Use Cases

![Infographic](/img/notes/2026-09/types-of-apis-and-their-use-cases.png)

## Summary
An API taxonomy maps common integration patterns—backend-to-backend, frontend-to-backend, service-to-database, B2B, partner, and data-sharing APIs—to practical use cases.

## Key points
- Backend-to-backend APIs support payment synchronization, token verification, stock updates, and other service integrations.
- Frontend-to-backend APIs handle login requests, profile fetches, and live search from user-facing applications.
- Service-to-database APIs support inserts, profile updates, and report queries while isolating database access.
- B2B, partner, and data-sharing APIs support hotel booking, payment gateways, affiliate links and commission tracking, click analytics, health records, finance data, and logistics tracking.
- The visual also contrasts REST, SOAP, GraphQL, and webhook-style interaction patterns.
