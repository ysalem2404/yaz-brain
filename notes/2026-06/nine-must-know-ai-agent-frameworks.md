# 9 Must-Know AI Agent Frameworks: ARR, OODA, GPS Check, and the New Value Equation

## Summary

A nine-panel mental-models reference for deciding when and how to use AI agents versus simpler alternatives. Frameworks include the ARR test (Autonomous/Recurring/Reviewable → use an agent; otherwise use a prompt), chatbot-vs-agent distinctions, the "4 Agent Workers" model (Analyst, Planner, Operator, Auditor coordinated by an LLM), prompt-vs-agent examples, the OODA loop (Observe-Orient-Decide-Act, attributed to Air Force Colonel John Boyd) as the test of whether an agent can find a better path when the obvious one fails, a pre-automation "GPS Check" (Goal, Proof, Steps), agent-vs-workflow distinctions, the principle that narrow ownership beats broad AI deployment, and a "new value equation" table contrasting pre- and post-agent economics (income tied to hours → scale your judgment; output scarce → output infinite; speed valuable → taste scarce; think fastest → define good work).

## Key Points

- ARR Framework: use an Agent if Autonomous+Recurring+Reviewable; otherwise use a Prompt
- Chatbot vs Agent: chatbot waits and predicts next word; agent decides its next move and sets destination
- 4 Agent Workers model: Analyst (finds pattern), Planner (decides plan), Operator (does work), Auditor (checks results), coordinated by an LLM
- OODA Loop (Col. John Boyd, USAF): real test of an agent is finding a better path when the obvious one fails
- GPS Check before automating: can you define the Goal, the Proof of success, and the Steps clearly?
- Narrow ownership wins: winners obsessively narrow scope rather than deploying AI everywhere
- New Value Equation: post-agent economics shift from hours-based income and scarce output to judgment-scaled, infinite-output, taste-driven work
