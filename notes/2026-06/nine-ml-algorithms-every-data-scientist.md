# 9 ML Algorithms Every Data Scientist Should Know

## Summary

A comprehensive nine-panel reference covering the core machine learning algorithms every data scientist should know: linear regression, logistic regression, decision trees, random forest, support vector machines, k-means clustering, gradient boosting (XGBoost), naive Bayes, and neural networks (MLP). Each panel includes a description, code snippet, use cases, and pros, functioning as a condensed field guide to classical and modern ML techniques.

## Key Points

- Linear/logistic regression as foundational regression and classification baselines
- Decision trees split data recursively and form the basis for ensembles like random forest and GBM
- Random forest: ensemble of decision trees, reduces overfitting, strong all-rounder
- SVM: finds optimal separating hyperplane, effective in high-dimensional spaces
- K-means clustering: unsupervised grouping by proximity to centroids
- Gradient boosting (XGBoost): sequential error-correcting trees, state-of-the-art for structured data
- Naive Bayes: fast probabilistic baseline for text/spam classification
- Neural networks (MLP): backbone of deep learning for complex non-linear pattern recognition
