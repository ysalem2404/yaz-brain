# The Microsoft AI Ecosystem: Five Layers From MAI Models to Enterprise AI

## Summary

Denis Panjuta's five-layer map of Microsoft's AI ecosystem: (1) MAI Models — Microsoft's in-house model family including MAI-Thinking-1 (complex reasoning), MAI-Code-1-Flash (fast coding), MAI-Image-2.5, MAI-Transcribe-1.5, MAI-Voice-2, and Frontier Tuning for business customization; (2) Copilot Layer — AI built into Microsoft products (M365 Copilot, GitHub Copilot, Copilot Studio, Windows Copilot, Security Copilot, Power Platform Copilot); (3) Microsoft Foundry — platform for building AI apps/agents (Foundry Models, Agent Service, Control Plane, Foundry IQ, Foundry Tools, Foundry Local); (4) Developer Ecosystem — tools for AI builders (VS Code, GitHub Copilot, Foundry SDKs, Agent Framework, Foundry Toolkit, Azure AI Services); (5) Enterprise AI Layer — AI for business/data/automation (Azure AI, Microsoft Fabric, Power BI Copilot, Power Apps, Power Automate, Dynamics 365 Copilot, Microsoft Purview).

## Key Points

- MAI Models layer names Microsoft's own in-house model family for the first time in Yaz's saved infographics: MAI-Thinking-1, MAI-Code-1-Flash, MAI-Image-2.5, MAI-Transcribe-1.5, MAI-Voice-2, plus Frontier Tuning for business customization
- Microsoft Foundry is positioned as the unified platform layer for building AI apps/agents, including a dedicated 'Control Plane' for safety and governance and 'Foundry IQ' for connecting company knowledge to AI
- Foundry Local is explicitly called out as enabling models to run on local devices — relevant to Yaz's interest in local/Ollama-style deployment
- Enterprise AI Layer explicitly includes Microsoft Purview for data security and governance, tying the ecosystem map directly to compliance concerns
- Developer Ecosystem layer separately lists the Agent Framework for building multi-agent systems and Foundry Toolkit for building/testing agents inside VS Code
