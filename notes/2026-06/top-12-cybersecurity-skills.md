# Top 12 Cybersecurity Skills

## Summary

Excellog.Biz's reference lists the 12 core cybersecurity skills: network security (firewalls, VPNs, IDS/IPS), threat analysis & intelligence (MITRE ATT&CK-based), SIEM (Splunk, Sentinel, QRadar), incident response & handling, vulnerability assessment/ethical hacking, cloud security (AWS/Azure/GCP shared responsibility model), identity & access management (MFA, SSO, RBAC), endpoint security/EDR (CrowdStrike, Carbon Black, Defender for Endpoint), application security (OWASP Top 10, API security), cryptography, risk management (ISO 27001, NIST, SOC 2, PCI DSS), and scripting/automation.

## Key Points

- 12 skills span network, threat intel, SIEM, incident response, vulnerability assessment, cloud, IAM, endpoint, appsec, cryptography, risk management, and scripting/automation
- SIEM skill names specific tools: Splunk, Microsoft Sentinel, IBM QRadar for log monitoring and anomaly detection
- Cloud security skill explicitly covers AWS, Azure, GCP workloads, IAM, and the shared responsibility model — directly relevant to multi-cloud enterprise environments
- Endpoint security skill names CrowdStrike, Carbon Black, and Microsoft Defender for Endpoint as representative EDR tools
- Risk management skill ties to named frameworks: ISO 27001, NIST, SOC 2, PCI DSS
