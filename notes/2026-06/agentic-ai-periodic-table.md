# Agentic AI Periodic Table: A Color-Coded Reference for LLM, RAG, MCP, A2A, and Agent Terminology

## Summary

GenAI.works' periodic-table-style reference organizes 70+ agentic AI terms into eight color-coded categories: AI Terminology (AAI, AGI, ASI, LLM, ML, RL), Vendor Tools (AWS, HuggingFace, Grok, Gemini, IBM ACP, Anthropic, OpenAI, Microsoft Azure, GCP), Agent Patterns (COL, HAA, PLAN, MAS), Capabilities & Skills (MAP, VOICE, IMG, IDEA, AZR, SUM, CAL, CHAT), Memory & Context Handling (CTX, FORG, SAVE, LTM, DIARY, NOTE, MEM), Evaluation & Safety (ERR, ACC, SAFE, TEST), Agent Collaboration & Networking (A2A, HELP, NET, ACP, CREW), Business & Use Cases (EDU, HR, MKT, SHOP, SUP, LEGAL), and Deployment & Scaling (MON, UPD, LOCAL, CLOUD, MCP).

## Key Points

- 70+ terms organized into eight color-coded categories in a chemistry-periodic-table visual metaphor
- MCP (Model Context Protocol) is defined as 'Standard for agents to connect with tools,' and A2A (Agent-to-Agent) as 'Agents communicating' — placing both foundational 2026 agent protocols side by side
- IBM ACP is distinguished from Anthropic's separate 'ACP' abbreviation used elsewhere for Agent Communication Protocol — note explicitly calls out overlapping/tailored abbreviations used for concise narrative visual purposes
- Includes both major AI vendors (AWS, HuggingFace, Grok, Gemini, Anthropic, OpenAI, Microsoft Azure, GCP) and abstract concepts (memory types: LTM long-term, STM short-term, DIARY, NOTE) in the same unified reference
- Explicit disclaimer footnote: 'this diagram uses both established and tailored abbreviations to capture complex concepts in a more concise and narrative visual'
