# Your Newest AI Agents Don't Need Better Models, They Need an Org Chart

## Summary

Carolyn Healey's framework argues agentic AI deployment is fundamentally a management and org-design problem, not a modeling problem. Cites Deloitte data that 84% of companies still have not redesigned jobs or the nature of work around AI capabilities. Proposes treating agents like employees across eight steps: write the job description before you 'hire' the agent (one clear scope, not 'handle everything'); set the authority scope in writing (what can it decide alone, what requires approval); give every agent a named owner (business and technical); treat agent identity as real identity (agents need their own permissions/lifecycle policies, not shared human credentials); design the escalation path, not just the happy path; build review into the system from day one (logs, audit trails, monitoring); put an agent manager over the team (orchestration layer as supervisor); hold performance reviews (track task success rate, escalation rate, cost per task, exception rate, compliance incidents, human override rate).

## Key Points

- Deloitte stat cited: 84% of companies still have not redesigned jobs or the nature of work around AI capabilities — the core evidence for the 'org chart, not better models' thesis
- Step 4 explicitly states agents need their own identities, permissions, lifecycle policies, and offboarding rules — 'if a human employee needs access governance, so does an autonomous digital worker'
- Step 7 frames the orchestration layer as literally 'your supervisor' — one agent retrieves, one validates, one checks policy, one escalates, coordination becoming the new scale frontier
- Step 8 performance review metrics are explicitly named: task success rate, escalation rate, cost per task, exception rate, compliance incidents, human override rate — 'do not run an agent fleet without performance management'
- Core thesis stated directly: deploying agentic AI is a hiring decision, an org-design decision, and a management problem — not primarily a model-selection problem
