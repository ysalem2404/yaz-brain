# Neural Network Fundamentals: Structure, Activation Functions, and Backpropagation

## Summary

A deep learning primer explaining how neural networks work end to end: what a neural network is, its layered structure (input, hidden layers, output), the five-step forward pass (input, weighted sum, activation function, forward propagation, backpropagation-based learning), the four major network types (feedforward, recurrent, convolutional, autoencoder), a comparison table of activation functions (sigmoid, tanh, ReLU, leaky ReLU) with formulas and purposes, and common application domains from image recognition to financial forecasting.

## Key Points

- Neural network: layered nodes that learn patterns and produce predictions
- Five-step process: input → weighted sum → activation function → forward propagation → backpropagation
- Four network types: FNN, RNN, CNN, autoencoders, each suited to different data shapes
- Activation function comparison: sigmoid (0-1, binary classification), tanh (-1 to 1, zero-centered), ReLU (fast, avoids vanishing gradient in hidden layers), leaky ReLU (avoids dead neurons)
- Applications: image recognition, speech recognition, NLP, autonomous vehicles, fraud detection, medical diagnosis, recommender systems, financial forecasting
- Key takeaway: networks learn via adjusting weights to minimize error, not by "thinking"
