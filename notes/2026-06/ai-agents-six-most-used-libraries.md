# AI Agents: 6 Most Used Libraries (LangChain, LangGraph, CrewAI, AutoGen, LlamaIndex, Semantic Kernel)

## Summary

A concise reference card naming the six most-used agent development libraries as of mid-2026: LangChain for building LLM apps with chains, tools, memory, and integrations; LangGraph for stateful multi-step agents built as graph workflows; CrewAI for collaborative multi-agent teams; AutoGen for agents that converse, collaborate, and automate tasks; LlamaIndex for connecting LLMs to data for RAG and retrieval; and Microsoft's Semantic Kernel for enterprise-ready AI applications with plugins, memory, and planning. Each entry is a one-line functional description rather than a deep comparison.

## Key Points

- LangChain: build LLM apps with chains, tools, memory, integrations
- LangGraph: stateful multi-step agents via graph-based workflows
- CrewAI: collaborative multi-agent teams
- AutoGen: agents that converse, collaborate, and automate
- LlamaIndex: connects LLMs to data for RAG and retrieval/search
- Semantic Kernel: Microsoft's enterprise-ready framework with plugins, memory, planning
