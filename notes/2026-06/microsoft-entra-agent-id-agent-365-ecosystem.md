# Microsoft Entra Agent ID: Bringing Identity to AI Agents Across the Agent 365 Ecosystem

## Summary

Aiswarya Venkitesh's diagram explains Microsoft Entra Agent ID as a system giving AI agents real identities — spanning authentication, authorization, identity protection, access governance, and visibility — now available for Foundry, Copilot Studio, Security Copilot, Microsoft 365 Copilot, and third-party agents. The bottom panel maps the broader 'Agent 365 Ecosystem,' showing Microsoft's Agent 365/Foundry hub connected via dashed lines to a wide vendor network: PolyAI, Cognition, LexisNexis, Workday, ServiceNow, Perplexity, CrewAI, Adobe, Anthropic, BlueYonder, Glean, WorkOS, Cursor, Manus, Nvidia, Sophos, Zendesk, Kasisto, Vercel, n8n, LangChain, Box, Zensai, Egnyte.

## Key Points

- Entra Agent ID covers five identity capabilities for AI agents specifically: Authentication, Authorization, Identity Protection, Access Governance, Visibility
- Already available for Microsoft's own agent platforms (Foundry, Copilot Studio, Security Copilot, Microsoft 365 Copilot) with third-party support also listed as available now
- Opens with framing: 'AI Agents are getting identities now. And that changes everything' — positioning agent identity as a pivotal 2026 shift
- Agent 365 Ecosystem map shows Microsoft's agent identity/orchestration hub connected to 24 named third-party vendors spanning conversational AI (PolyAI), coding agents (Cursor, Cognition), knowledge management (Glean, Box, Egnyte), and workflow automation (n8n, LangChain)
- Perplexity is explicitly named as one of the connected ecosystem partners

## Why Yaz Saved This

Directly relevant to Yaz's identity-and-access-management interests within Microsoft's ecosystem — Entra Agent ID extending Azure AD-style identity governance to AI agents is a concrete building block for his enterprise agent security architecture at Bechtel.
