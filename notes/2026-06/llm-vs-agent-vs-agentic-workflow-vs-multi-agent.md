# LLM vs Agent vs Agentic Workflow vs Multi-Agent System: Autonomy Spectrum Compared

## Summary

Brij Kishore Pandey's terminology comparison distinguishes four commonly conflated concepts along an autonomy spectrum: LLM (low autonomy — single-step generation, best for chat/summarization/drafting), Agent (medium autonomy — goal-driven, uses tools, plans and retries, best for task execution and troubleshooting), Agentic Workflow (medium-high autonomy — structured, deterministic steps with optional human approval, best for business processes and document pipelines), and Multi-Agent System (high autonomy — specialized agents collaborating via shared memory/coordination, best for complex projects and large workflows). The quick-reference summary maps each to a single verb: LLM=Generate, Agent=Act, Agentic Workflow=Orchestrate, Multi-Agent System=Collaborate.

## Key Points

- LLM (Low autonomy): single-step response, no real autonomy, best for chat/summarization/Q&A
- Agent (Medium autonomy): goal-driven, uses tools, plans and retries, maintains state, best for task execution
- Agentic Workflow (Medium-High autonomy): predefined deterministic steps with optional human approval, best for repeatable business processes
- Multi-Agent System (High autonomy): specialized agents collaborate via shared memory/coordination, best for complex multi-step problems
- Quick mapping: LLM=Generate, Agent=Act, Agentic Workflow=Orchestrate, Multi-Agent System=Collaborate
- Decision guide: one answer→LLM; one system to act→Agent; repeatable controlled steps→Agentic Workflow; many specialized workers→Multi-Agent System
