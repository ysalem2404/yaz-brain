# My AI Tech Stack: Antigravity, Claude Code + Codex, Hermes Agent, GitHub

## Summary

A personal AI tech stack breakdown organized as Workspace → Build → Orchestrate → Govern, arguing 'the tools matter less than the workflow.' Antigravity is the AI-first workspace for organizing and navigating software projects (red flag: interface mistaken for workflow, tool driving architecture). Claude Code + Codex are coding agents for reading/editing/debugging code (red flag: code accepted without review, tests skipped because output looks right). Hermes Agent is a personal AI operating layer for context, memory, orchestration, and follow-through (red flag: agents given authority without boundaries). GitHub is the source of truth for code, history, and review (red flag: AI bypasses pull requests, no commit discipline).

## Key Points

- Four-stage personal stack: Workspace (Antigravity) → Build (Claude Code + Codex) → Orchestrate (Hermes Agent) → Govern (GitHub)
- Each tool has explicit 'red flags' to watch for — a self-aware risk checklist rather than pure tool promotion
- Claude Code + Codex red flags include 'code accepted without review' and 'tests skipped because output looks right' — a direct warning against over-trusting coding agents
- GitHub is framed as the 'govern' layer specifically for audit trail, branch/version control, and preserving review discipline against AI-generated changes
- Core thesis explicitly stated: 'The tools matter less than the workflow' — sequencing and discipline matter more than any specific product choice
