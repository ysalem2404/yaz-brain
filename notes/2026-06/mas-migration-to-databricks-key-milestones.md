# MAS Migration to Databricks — Key Milestones

![Infographic](/img/notes/2026-06/mas-migration-to-databricks-key-milestones.png)

## Summary
A milestone timeline describes an MAS platform modernization: assessment in 2024, a replacement-platform project, a 2025 migration effort, and Databricks becoming the agreed platform for sourcing and ingesting data.

## Key points
- An assessment established the starting state of the MAS platform
- A follow-on project scoped decommissioning and selected the replacement platform
- The migration moved the MAS system toward Databricks as the data platform
- The current state emphasizes Databricks as the source and ingestion platform for required MAS data
