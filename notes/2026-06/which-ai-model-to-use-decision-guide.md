# Which AI Model to Use: A 10-Category Decision Guide

## Summary

Alok Sharan's decision guide maps ten common AI use-case categories to the best-fit models for each: general chat/productivity (ChatGPT, Claude, Grok, Pi), advanced reasoning (Claude, Deepseek, Gemini, Yi-34B, Mistral), coding (GitHub Copilot, ChatGPT, Claude, StarCoder2), creative writing, search/research (Perplexity, ChatGPT, Grok, You.com), long document analysis, multi-modal tasks, open-source/self-hosted options (Deepseek, Yi-34B, Mistral, StarCoder2, GPT4All), enterprise/secure use (ChatGPT, Claude, Gemini, Copilot, LM Studio), and education/tutoring.

## Key Points

- General chat/productivity: ChatGPT, Claude, Grok, Pi (Inflection AI)
- Advanced reasoning and problem solving: Claude, Deepseek, Gemini, Yi-34B, Mistral
- Coding tasks: GitHub Copilot, ChatGPT, Claude, StarCoder2
- Search/research/web knowledge: Perplexity, ChatGPT, Grok, You.com
- Open-source/self-hosted: Deepseek, Yi-34B, Mistral, StarCoder2, GPT4All
- Enterprise/secure use: ChatGPT, Claude, Gemini, Copilot, LM Studio
- Framed as a decision flow across 10 categories rather than a single best-model ranking
