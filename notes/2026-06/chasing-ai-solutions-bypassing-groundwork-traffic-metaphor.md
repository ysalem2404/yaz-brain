# Chasing AI Solutions, Bypassing the Groundwork: The Traffic Jam Metaphor

## Summary

Clare Kitching's illustrated highway metaphor shows a jammed lane of cars all following a 'Pilot Shortcut' sign toward exits for 'AI Solutions,' 'Workflow Redesign,' and 'Data Fundamentals,' while a nearly empty lane runs alongside signposted the same three destinations without the shortcut. The visual argues most organizations take a rushed pilot shortcut that leads to the same overloaded destination, while the disciplined route (working through workflow redesign and data fundamentals properly) moves faster despite looking slower at first.

## Key Points

- Visual metaphor: 'Pilot Shortcut' lane is jammed bumper-to-bumper; the disciplined lane following the same signposted destinations (AI Solutions, Workflow Redesign, Data Fundamentals) is nearly empty and moving freely
- Argues that skipping workflow redesign and data fundamentals to rush a pilot doesn't actually save time — it creates congestion later
- Reinforces a recurring theme across Yaz's saved strategy content: the 'shortcut' to AI value is usually the slower path in practice
- No explicit numbered framework — purely an illustrative reinforcement of the workflow-first, data-first message
