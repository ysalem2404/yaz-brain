# SaaS Security Detection — Tips to Get Started

![Infographic](/img/notes/2026-06/saas-security-detection-tips-to-get-started.png)

## Summary
A detection guide recommends user-agent baselining, IP-prevalence scoring, and cross-service identity correlation as starting points for finding anomalous SaaS activity.

## Key points
- Baseline user agents across integrations and flag deviations from known tool signatures
- Score IP prevalence and suppress common infrastructure to surface rare-IP events
- Normalize identity fields before joining events across SaaS applications
