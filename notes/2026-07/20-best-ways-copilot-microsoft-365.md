# 20 Best Ways to Use Copilot in Microsoft 365 Apps

## Summary

A practical productivity infographic listing 20 concrete Copilot use cases across PowerPoint (slide creation, rewriting, design, visuals, summarization), Word (drafting, tone rewriting, summarizing, key info extraction, table creation), Excel (data analysis, formulas, charts, cleaning, forecasting), and code tasks (generation, explanation, debugging, refactoring, translation). Additional cross-app uses include meeting summarization, email drafting, research, and action-plan creation.

## Key Points

- PowerPoint: generate slides from scratch, rewrite content, apply design themes, auto-add visuals
- Word: draft documents, rewrite for tone, summarize long documents, extract key info, build tables
- Excel: instant data analysis, AI-generated formulas, automatic charts, data cleaning, forecasting
- Code: generate from prompt, explain/document, debug and fix, refactor/optimize, translate across languages
- Additional uses: summarize Teams meetings, draft emails, research and learn faster, create action plans
