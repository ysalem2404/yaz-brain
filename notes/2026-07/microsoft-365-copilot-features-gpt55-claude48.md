# Microsoft 365 Copilot Features — GPT-5.5 and Claude 4.8 Opus Model Choice

## Summary

An AIForLeaders.com infographic detailing new Microsoft 365 Copilot capabilities across Word, Excel, PowerPoint, and Teams. It highlights a new model selector offering GPT-5.5 (Instant and Think Deeper modes) and Claude 4.8 Opus, now available in Excel and set as the default model in Microsoft Copilot. Feature highlights include Word's 'Catch Up on Recent Changes' summarization, planned Excel changes requiring approval before edits apply, PowerPoint's 'Grill Your Deck' audience-question prediction, and Teams' ability to delete meeting recaps for off-topic meetings.

## Key Points

- New model selector in Copilot: GPT-5.5 Instant, GPT-5.5 Think Deeper, and Claude 4.8 Opus
- Claude 4.8 Opus is now the default model in Microsoft Copilot and available in Excel
- Word adds 'Catch Up on Recent Changes' to summarize document edits across versions
- Planned Excel workflow: Copilot reviews data, asks clarifying questions, proposes a plan, and applies changes only after user approval
- PowerPoint's 'Grill Your Deck' analyzes a presentation to predict likely audience questions
- Teams adds a 'Delete Meeting Recap' control to remove off-topic meeting recaps
