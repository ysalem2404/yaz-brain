# Cybersecurity Frameworks Guide — NIST CSF, ISO 27001, CIS Controls, CISA ZTMM, MITRE ATT&CK

## Summary

An Excellog.Biz infographic summarizing five major cybersecurity frameworks with their key focus and best-fit use case: NIST CSF 2.0 (govern/identify/protect/detect/respond cyber risk; best for cyber strategy and board reporting), ISO/IEC 27001:2022 (ISMS scope, risk treatment, controls, audits; best for certification readiness and supplier trust), CIS Controls v8.1 (prioritized safeguards for common attacks; best for cyber hygiene and cloud hardening), CISA Zero Trust Maturity Model v2.0 (identity/device/network/data verification; best for zero-trust planning and hybrid work), and MITRE ATT&CK v19 (adversary behavior mapping; best for SOC teams and threat hunting). It closes with a compliance note that overlapping regulations (PCI DSS, SOC 2, DORA, NIS2, CMMC, HIPAA, GDPR) should be mapped into one unified control set.

## Key Points

- Five frameworks compared: NIST CSF 2.0, ISO/IEC 27001:2022, CIS Controls v8.1, CISA ZTMM v2.0, MITRE ATT&CK v19
- Each framework paired with a specific best-fit use case (board reporting, certification, cloud hardening, zero-trust, threat hunting)
- Recommends mapping overlapping compliance regimes (PCI DSS, SOC 2, DORA, NIS2, CMMC, HIPAA, GDPR) into a single control set rather than treating them separately
- CIS Controls v8.1 specifically called out as best for small teams and control rollout, distinct from enterprise-scale NIST CSF usage
- MITRE ATT&CK framed as detection/threat-hunting tool rather than a governance or compliance framework
- Useful quick-reference when deciding which framework to lead with for a given security conversation
