# How an AI Agent System Works — 9-Step Connected Ecosystem

## Summary

A Greg Coquillo infographic walking through nine steps of a connected AI agent ecosystem: (1) User Query arrives, (2) RAG retrieves relevant context like a library, (3) the LLM brain reasons through the problem, (4) Memory recalls stored context like a notebook, (5) Tools act as hands to search/email/code/run workflows, (6) MCP acts as a universal adapter connecting the agent to external apps/data, (7) A2A (agent-to-agent) protocol lets agents share info and delegate tasks, (8) a Multi-Agent system of specialized agents (Research, Planning, Execution, Review) works toward a shared goal, and (9) the Final Response/Action is delivered back to the user.

## Key Points

- Nine-step flow from user query to final delivered response/action
- RAG explicitly analogized to a 'library' and Memory to a 'notebook' for intuitive understanding
- MCP framed as a 'universal adapter' connecting the LLM to external apps/data (web search, email, CRM/SaaS, databases, files, APIs)
- A2A protocol shown as the mechanism enabling info sharing and task delegation between agents
- Multi-agent team example includes four specialized roles: Research, Planning, Execution, and Review agents sharing one goal
- Closing linear flow diagram compresses the full 9 steps into a single reference strip
