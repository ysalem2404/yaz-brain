# AI Agent Architecture Cheat Sheet — 9-Box Reference Grid

## Summary

A nine-box reference grid by @sambit.ai.tech summarizing the core components of AI agent architecture: LLM/Brain (the reasoning core), Memory (short and long-term state), RAG (external knowledge retrieval), Tools (action execution), Planning (task decomposition), Reflection (self-critique), Multi-Agent (coordination across agents), Monitoring & Guardrails (safety), and Human-in-the-Loop (oversight). Designed as a fast-reference cheat sheet rather than a deep explainer.

## Key Points

- Nine core components: LLM/Brain, Memory, RAG, Tools, Planning, Reflection, Multi-Agent, Monitoring & Guardrails, Human-in-the-Loop
- Positions Memory and RAG as distinct but complementary knowledge sources
- Planning and Reflection are treated as separate agent capabilities (decomposition vs self-critique)
- Monitoring & Guardrails and Human-in-the-Loop are both listed as safety-oriented boxes
- Intended as a compact cheat-sheet rather than a full architectural spec
