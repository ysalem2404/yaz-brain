# Microsoft AI Ecosystem — 5 Layers (MAI, Copilot, Foundry, Dev, Enterprise)

![Infographic](public/img/notes/2026-07/microsoft-ai-ecosystem-5-layers.png)

## Summary
5-layer decomposition of the MS AI stack: (1) MAI Models — MS's in-house model family: MAI-Thinking-1 (reasoning), MAI-Code-1-Flash (coding), MAI-Image-2.5 (image gen/edit), MAI-Transcribe-1.5 (STT), MAI-Voice-2 (TTS), Frontier Tuning (customization); (2) Copilot Layer — M365, GitHub, Studio, Windows, Security, Power Platform Copilots; (3) Microsoft Foundry — Foundry Models, Agent Service, Control Plane (governance), Foundry IQ (knowledge connect), Foundry Tools, Foundry Local (on-device); (4) Developer Ecosystem — VS Code, GitHub Copilot, Foundry SDKs, Agent Framework, Foundry Toolkit, Azure AI Services; (5) Enterprise AI Layer — Azure AI, Fabric, Power BI Copilot, Power Apps, Power Automate, Dynamics 365 Copilot, Purview.

## Key points
- MAI = Microsoft's own frontier model family — 6 named variants + Frontier Tuning
- Microsoft Foundry is the new central platform brand — 6 sub-services
- Foundry Local = on-device inference (competes with Ollama story)
- Control Plane explicitly names 'safety & governance' as a distinct Foundry service
