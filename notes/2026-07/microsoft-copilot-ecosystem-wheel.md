# Microsoft Copilot Ecosystem — Full Product Wheel

![Infographic](public/img/notes/2026-07/microsoft-copilot-ecosystem-wheel.png)

## Summary
Circular ecosystem map organizing the entire Microsoft AI portfolio into 10 wedges: Power Platform, Modern Work (M365 apps), Business Applications (Dynamics 365), Security (Defender/Sentinel/Purview/Entra/Intune), Data & AI (Azure OpenAI, Foundry, AI Search, Vision, Speech, Language, ML, Fabric, Databricks), Browser & Search (Edge, Bing), AI & Agents (Azure AI Agent Service, Prompt Flow, Fine-Tuning, Model Catalog, Distillation, Content Safety, Responsible AI Dashboard), Operating Systems (Windows 11 Copilot + built-in AI apps), Azure Platform (App Service, Functions, SQL, Cosmos, Logic Apps, Monitor, AKS), Developer (GitHub Copilot, VS, VS Code, Azure DevOps, Loop), Collaboration (Teams, Exchange, OneDrive, SharePoint), Business Intelligence (Fabric, Synapse, OneLake, Power BI).

## Key points
- Copilot appears 6+ times as its own product (M365, GitHub, Studio, Windows, Security, Power Platform, Fabric, Dynamics variants)
- Foundry is the new umbrella for agent/model dev — replaces older Azure ML branding for some workflows
- Purview + Entra + Intune + Defender + Sentinel = the 5-piece MS AI security stack
- Fabric now has its own Copilot
- AI & Agents wedge treats Azure AI Agent Service as a distinct product from Copilot Studio
