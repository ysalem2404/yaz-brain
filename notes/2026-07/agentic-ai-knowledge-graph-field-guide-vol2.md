# The Agentic AI Knowledge Graph — Field Guide Vol. 02

## Summary

A Brij Kishore Pandey 'field guide' organizing agentic AI concepts into five dependency layers from Foundations up to Frontier: Layer 1 Foundations (LLM reasoning, prompt patterns, tool use/function calling, embeddings/vectors, context windows); Layer 2 Retrieval & Memory (classical/graph/agentic RAG, short/long-term/episodic memory); Layer 3 Agent Patterns (ReAct loop, planner-executor, multi-agent orchestration, context graph traversal, tool selection/routing, reflection/self-critique); Layer 4 Production & Governance (confidence scoring, policy gates, audit trail design, decision reasoning logs, eval/observability, cost/token economics); and Layer 5 Frontier (memory/learning loops, self-improving agents, multi-modal reasoning, agentic workflows at scale). The guide argues agentic AI must be learned by tracing dependencies bottom-up, not top-down.

## Key Points

- Five dependency layers: Foundations, Retrieval & Memory, Agent Patterns, Production & Governance, Frontier
- Explicitly warns 'you don't start here' at the Frontier layer — most teams try to skip to advanced concepts prematurely
- Context Graph Traversal highlighted as the central agent pattern connecting retrieval to production concerns
- Production & Governance layer treated as a prerequisite dependency for Frontier capabilities, not an afterthought
- Closing thesis: agentic AI must be learned by tracing dependencies bottom-up and watching one run end-to-end
- Companion piece to the same author's other agentic AI infographics (AI Agent Factory, Anatomy of an Agent Harness) in this batch

A structured learning roadmap for Yaz's own agentic AI skill development — the explicit warning against skipping to 'Frontier' concepts before mastering foundations is a useful check against superficial AI adoption at Bechtel.
