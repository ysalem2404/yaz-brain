# The AI Agent Factory — 10-Component Production Analogy

## Summary

An infographic mapping ten AI agent architecture components to a factory-production analogy: User Goal = Work Order, LLM = Reasoning Engine, Agent Harness = Assembly Line, Context/RAG = Materials Supply, Memory = Shift Log, Tools = Machines, MCP = Connector Standard, Sandbox = Secure Work Cell, Guardrails = Safety System, and Observability + Evals = Control Room + QA. The closing line argues the model is only one machine and production AI needs the whole factory.

## Key Points

- Ten components mapped one-to-one to factory production roles
- Sandbox explicitly framed as a 'secure work cell' for controlled code/action execution
- MCP framed as a 'connector standard' rather than a protocol abstraction
- Memory positioned as a 'shift log' — state carried between work sessions
- Closing thesis: the model is one machine among many required for production AI
- Simple analogy format aimed at non-technical stakeholders explaining agent architecture

## Why Yaz Saved This

A stakeholder-friendly analogy Yaz can use when explaining agent architecture components to non-technical Bechtel leadership — reframes technical AI infrastructure in familiar industrial/manufacturing terms relevant to an EPC audience.
