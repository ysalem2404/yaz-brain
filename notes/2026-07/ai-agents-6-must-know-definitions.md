# AI Agents: 6 Must-Know Definitions (MCP, Single/Multi-Agent, Skills, Agentic RAG, Memory)

## Summary

Jason Moccia's six-panel glossary defines the core vocabulary of AI agent systems: Model Context Protocol (MCP) as the standard connecting models to tools/data/services; Single-Agent Architecture for simple, well-defined tasks; Skills as reusable capabilities (web search, code execution, data analysis, email); Multi-Agent Architecture where a manager agent delegates to specialized research/analysis/execution agents sharing memory; Agentic RAG where the agent decides what to retrieve and how to use it; and Memory as the component storing short-term/session and long-term/persistent context, knowledge bases, vector stores, and preference profiles.

## Key Points

- MCP defined as a standard letting AI models connect to tools, data sources, and external services in a consistent, tool-agnostic, secure way
- Single-agent architecture: simple to build, suitable for well-defined tasks, but limited scalability
- Multi-agent architecture: specialized agents (Research, Analysis, Execution) coordinated by a Manager Agent sharing a common memory/knowledge store
- Skills are named as reusable actions an agent can invoke — web search, code execution, data analysis, email sending — to break complex tasks into steps
- Agentic RAG distinguished from classic RAG by the agent actively deciding what to search, where, and how to use retrieved information
- Memory taxonomy: short-term (session) vs long-term (persistent), plus knowledge base, vector store, and preferences/profiles as sub-components
