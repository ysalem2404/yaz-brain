# Top 8 Open-Source AI Models for Reasoning, Coding, Agents and Self-Hosting in 2026

## Summary

A comparison infographic of 8 leading open-source AI models for self-hosted and agentic use in 2026: gpt-oss-120B (OpenAI, 117B MoE, Apache 2.0), Ling-1T (InclusionAI, trillion-parameter MoE), MiniMax-M2.5, Kimi-K2.5 (1T parameter multimodal MoE, 256K context), GLM-5 (Zhipu AI, 744B parameters, coding-optimized), MiMo-V2-Flash (Xiaomi, 309B/15B active MoE), Qwen3.5-397B (Alibaba, 262K+ context), and DeepSeek-V3.2 (MIT-licensed, sparse attention). Each lists features and primary use cases.

## Key Points

- gpt-oss-120B: 117B MoE, adjustable reasoning depth, Apache 2.0 license for commercial use
- Ling-1T: trillion-parameter MoE with evolutionary chain-of-thought reasoning
- Kimi-K2.5: 1T parameters, native multimodal, up to 256K token context
- GLM-5: 744B parameters optimized for coding/reasoning with sparse attention for long context
- Qwen3.5-397B: ultra-long context up to 262K+ tokens, multimodal, strong for agents/RAG
- DeepSeek-V3.2: MIT-licensed, sparse attention, reasoning-heavy and tool-calling use cases
