# Microsoft Azure Ecosystem for AI Agents — 2026 Product Map

## Summary

A comprehensive 2026 map of Microsoft's Azure and Microsoft 365 product surface for building and running AI agents, compiled by Greg Coquillo. It organizes the ecosystem into build tools (Azure AI Foundry, Semantic Kernel, Copilot Studio), identity and governance (Microsoft Entra Agent ID), knowledge/retrieval (Azure AI Search), and operational/management layers (Microsoft Agent 365). The chart is intended as a single-glance reference for where each Microsoft product fits in an enterprise agent build.

## Key Points

- Maps the full Microsoft/Azure agent stack: build, identity, retrieval, and operations layers
- Azure AI Foundry positioned as the core agent build and orchestration surface
- Semantic Kernel shown as the SDK/orchestration layer for custom agent code
- Copilot Studio positioned as the low-code/no-code agent authoring surface
- Microsoft Entra Agent ID introduced as identity and access management for non-human agent identities
- Microsoft Agent 365 shown as the operational management plane across agents

## Why Yaz Saved This

Directly relevant to Yaz's Microsoft-ecosystem-heavy enterprise architecture work — a single reference map for how Azure AI Foundry, Entra Agent ID, and Agent 365 fit together when designing agent solutions for Bechtel's Azure GCCH environment.
