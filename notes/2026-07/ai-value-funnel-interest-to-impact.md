# The AI Value Funnel — From Interest to Measurable Impact

## Summary

A Clare Kitching infographic modeling how AI value moves through five funnel stages — Opportunity, Readiness, Experimentation, Adoption, and Scale — with each stage paired against where value typically gets lost and what leaders should do instead. Value is lost when teams chase visible-but-low-value use cases, skip data readiness, test tools instead of outcomes, fail to redesign workflows around adoption, or fail to reuse wins across teams at the scale stage.

## Key Points

- Five-stage funnel: Opportunity, Readiness, Experimentation, Adoption, Scale
- At Opportunity stage, value is lost by chasing visible demos over valuable problems; fix is picking by value, not visibility
- At Readiness stage, poor data quality and no named owner cause value loss
- At Experimentation stage, 'it runs' is often mistaken for 'it helps' — leaders should measure the outcome and stop if the number doesn't move
- At Adoption stage, pilots succeed technically but nobody uses them if the workflow itself isn't redesigned
- At Scale stage, value is lost when wins stay siloed in one team instead of being reused across the organization
