# Cybersecurity Tools Taxonomy by Excellog.Biz

## Summary

A structured mind-map of cybersecurity tool categories: Security Governance & Policy (ISO 27001, NIST CSF, policy management), Threat Detection & Monitoring (SIEM, SOC, UEBA), Vulnerability & Risk Management, Incident Response & Forensics, Identity & Access Management (IAM, MFA, PAM), Network & Endpoint Security (firewall, EDR, IDS/IPS), and Data Protection & Compliance (encryption, DLP, regulatory monitoring). Each branch pairs a tool category with its one-line purpose.

## Key Points

- Seven top-level categories span governance through compliance monitoring
- Threat detection cluster: SIEM, SOC, and UEBA for centralized monitoring and anomaly detection
- IAM cluster covers MFA and Privileged Access Management alongside core IAM
- Network/endpoint cluster includes firewall, EDR, and IDS/IPS
- Data protection cluster covers encryption, DLP, and regulatory compliance monitoring
- Framed as a reference taxonomy rather than vendor-specific product list

## Why Yaz Saved This

General-purpose cybersecurity taxonomy useful as a checklist when mapping AI system security controls to existing enterprise security tooling categories in a Bechtel/FedRAMP environment.
