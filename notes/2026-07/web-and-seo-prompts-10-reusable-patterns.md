# Web and SEO Prompts — 10 Reusable Patterns

![Infographic](public/img/notes/2026-07/web-and-seo-prompts-10-reusable-patterns.png)

## Summary
A ten-prompt web and SEO playbook for keyword research, title and meta writing, on-page audits, homepage rewrites, Core Web Vitals remediation, local search, and Google Business Profile prioritization.

## Key points
- Keyword prompts pair search intent with content ideas and a ranked starting set
- Technical prompts cover title tags, metadata, headings, internal links, LCP, INP, CLS, image formats, and script loading
- Local SEO prompts organize category selection, profile completeness, photos, review requests, and reply workflows

## Why I saved this
A reusable prompt set for turning broad web-growth goals into concrete content, technical, and local-search actions.

Prompts

Prompt 1

Irun [BUSINESS] and want to get found on
Google. Suggest 20 keywords real customers
would search for [TOPIC], each with the likely
search intent (informational, commercial, or
transactional) and a content idea to target it.
Return as a table sorted from easiest to rank to
hardest, and flag the 5 best to start with.

Prompt 3

Write 5 title tag and meta description options
for my page about [PAGE TOPIC] targeting
[KEYWORD]. Keep each title under 60
characters with the keyword near the front,
and each description 150-160 characters that
earns the click without keyword stuffing.
Return as a numbered table with character
counts shown.

Prompt 5

My site [URL] feels slow and fails Core Web
Vitals. Explain LCP, INP, and CLS in plain
English with their good thresholds (LCP under
2.58, INP under 200ms, CLS under 0.1), then
give me a prioritized checklist of fixes for a
non-developer, like compressing images to
WebpP, deferring scripts, and setting image
dimensions.

7/12

6/10 Web

Prompt 2

Act as an SEO auditor. Here is the page:
[PASTE URL OR TEXT]. Check it against
on-page basics: title tag, meta description, one
clear H1, logical heading order, keyword and
intent match for [KEYWORD], readability, and
internal links. Return a table of issue, why it
matters, and the exact fix, ranked by impact.

Prompt 4

Rewrite my homepage copy for [BUSINESS],
which helps [AUDIENCE] achieve
[OUTCOME]. Lead with a headline that
answers ‘what's in it for me’ in 5 seconds, sell
benefits over features, and end with one
action-verb CTA. Give me a headline,
subheadline, 3 benefit bullets, and a button
label, plus 2 alternate headlines.

Prompt 6

I own a local [BUSINESS TYPE] in [CITY] and
want to rank in Google Maps. Audit my Google
Business Profile priorities: best primary and
secondary categories, every field to fill, a photo
plan, and a simple system to earn and reply to
reviews. Return a checklist grouped by 'do
today’, 'this week’, and ‘ongoing’.
