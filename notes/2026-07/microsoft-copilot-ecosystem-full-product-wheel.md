# Microsoft Copilot Ecosystem — Full Product Wheel

## Summary

An Ananya Ghosh Chowdhury wheel diagram mapping the full Microsoft Copilot ecosystem across nine domains around a central Copilot icon: Power Platform, Modern Work (M365 apps), Business Applications (Dynamics 365), Security (Defender/Sentinel/Entra/Purview), Developer (GitHub Copilot/Visual Studio/Azure DevOps), Collaboration (Teams/Exchange/SharePoint), Azure Platform, Operating Systems (Windows Copilot), Browser & Search, AI & Agents, Data & AI (Azure OpenAI/Foundry/Databricks), and Business Intelligence. Each domain lists 4-10 specific named products.

## Key Points

- Nine-domain wheel covering the full breadth of Microsoft's Copilot-branded product surface
- Data & AI domain includes Azure OpenAI Service, Azure AI Foundry, and Azure Databricks together
- Security domain groups Defender XDR, Defender for Cloud, Sentinel, Entra ID, and Purview under Copilot-integrated security
- AI & Agents domain separately lists Azure AI Agent Service, Prompt Flow, Fine-Tuning, Model Catalog, Model Distillation, and Responsible AI Dashboard
- Developer domain includes GitHub Copilot, Visual Studio, VS Code, Azure DevOps, and Copilot Studio
- Serves as the single most comprehensive Microsoft product map captured in this ingestion run
