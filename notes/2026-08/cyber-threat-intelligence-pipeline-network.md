# Cyber Threat Intelligence — Pipeline Network

![Infographic](/img/notes/2026-08/cyber-threat-intelligence-pipeline-network.png)

## Summary
A pipeline architecture turns collected threat data into normalized, semantic intelligence that can feed detection logic and rules while retaining raw and contextual layers.

## Key points
- Data collectors feed semantic transformers before information is organized into a shared threat-intelligence representation.
- The network branches into detection-oriented outputs such as CDC and detection rules, enabling downstream security analytics.
- Raw archive and snapshot/context layers preserve source material and the state used to interpret or reproduce detections.
