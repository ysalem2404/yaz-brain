# AI Agents — 6 Must-Know Terms (Part 2)

![Infographic](public/img/notes/2026-08/ai-agents-6-must-know-terms-pt2.png)

## Summary
Six foundational agent concepts explained visually: (1) MCP as universal standard from Anthropic for connecting AI to tools/data ('USB-C for AI'), (2) Agent Loops — autonomous iterative Action/Observation cycles until completion, (3) Skills — the specific tools/capabilities an agent can leverage, (4) Single vs Multi-Agent Architecture trade-off (simplicity vs specialization), (5) Agentic RAG — agents dynamically routing queries, validating retrievals, and deciding on re-retrieval, (6) Agent Memory with short-term (context window) and long-term (retrieval-based) layers plus write control, dedup, reconciliation, amendment, purposeful forgetting.

## Key points
- MCP framed as 'USB-C for AI' — one protocol replaces custom integrations
- Agent loops are the definitional difference from chatbots — autonomous iteration, no per-step prompting
- Agentic RAG > traditional RAG: agents can validate retrievals and re-query
- Memory layer has 5 sub-capabilities: write control, deduplication, reconciliation, amendment, purposeful forgetting

## Entities & tools mentioned
Model Context Protocol, Anthropic, LangGraph, MCP, Agentic RAG

Part 2 of a primer series — the memory sub-capabilities (dedup, reconciliation, purposeful forgetting) are exactly what Yaz is architecting for enterprise agent governance. Good building-block reference for team enablement decks.
