# The AI Systems Factory

![Infographic](public/img/notes/2026-08/the-ai-systems-factory.png)

## Summary
A production-AI systems diagram frames real-world results as a factory made from an LLM, retrieval, vector storage, agents, MCP tool connections, guardrails, and evaluation.

## Key points
- The LLM generates text, reasons, explains, and creates
- RAG finds relevant information before the model answers, while a vector database retrieves by meaning
- Agents decide next steps and use tools; MCP connects agents to apps, APIs, files, and databases
- Guardrails define allowed behavior and evaluations measure correctness, safety, cost, latency, and success

## Why I saved this
A clear systems view that shifts attention from model choice to the surrounding production architecture.
