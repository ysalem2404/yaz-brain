# Agentic AI Terms and Use Cases

![Infographic](public/img/notes/2026-08/agentic-ai-terms-and-use-cases.png)

## Summary
An agentic-AI landscape distinguishes levels of autonomy and lists the terms, tools, and business use cases associated with agent-based software.

## Key points
- Terms include autonomy, agentic software, goal chaining, orchestration, tool use, observability, governance, guardrails, memory, and multi-agent collaboration
- Use cases include contract management, content and code generation, outreach, expense processing, forecasting, recommendations, order tracking, support, and employee assistants
- The map names model providers and orchestration or automation tools such as Claude, Gemini, ChatGPT, Codex, Copilot, LangChain, AutoGen, n8n, Zapier, and MCP
