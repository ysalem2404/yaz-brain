# Static vs Contextual Embeddings

![Infographic](public/img/notes/2026-08/static-vs-contextual-embeddings.png)

## Summary
Static embeddings assign one fixed vector to each word, while transformer-based contextual embeddings produce different vectors for the same word based on its surrounding sentence.

## Key points
- Static methods such as Word2Vec, GloVe, and FastText learn one vector per word.
- Contextual methods such as BERT and GPT adjust each token representation using surrounding words, allowing one word to carry different meanings.

## Why I saved this
A clear comparison of the shift from corpus-level word similarity to context-sensitive meaning.
