# 20 Databricks Concepts Every Data Engineer Should Know

![Infographic](/img/notes/2026-08/20-databricks-concepts-every-data-engineer-should-know.png)

## Summary
A concept map covers the Databricks lakehouse, Delta Lake, medallion layers, Unity Catalog, data sharing, SQL warehouses, workflows, streaming, and performance optimization.

## Key points
- The lakehouse combines data-lake flexibility with warehouse reliability
- Delta Lake adds ACID transactions, schema enforcement, time travel, and progressive bronze-silver-gold refinement
- Unity Catalog centralizes governance, access control, lineage, discovery, and secure sharing
- Workflows, Auto Loader, DLT, OPTIMIZE, and vectorized query execution support production pipelines
