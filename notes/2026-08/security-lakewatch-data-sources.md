![Infographic](/img/notes/2026-08/security-lakewatch-data-sources.png)

## Summary
A photographed Databricks Lakewatch screen shows a security-operations workspace bringing multiple event sources into one place for monitoring and detection.

## Key points
- Visible data sources include Groundstrike ES, Groundstrike EDR, Workday Activity Log, Microsoft Entra, Akamai WAF, Slack Audit Log, and GitLab.
- The workspace includes configuration for datasources and detection rules, plus security cases, system cases, observables, queries, dashboards, and a lakehouse.
- The screen illustrates a unified security-data surface rather than a detailed product specification.
