# AWS Concepts Roadmap

![Infographic](public/img/notes/2026-08/aws-concepts-roadmap.png)

## Summary
An AWS concepts roadmap groups core cloud services across networking, compute, storage, databases, security, serverless, containers, delivery, and operations.

## Key points
- The map connects foundational networking and identity concepts such as VPCs, routing, peering, security groups, VPN, IAM, and key management
- Compute and application paths include EC2, Auto Scaling, Elastic Beanstalk, Lambda, ECS, EKS, API Gateway, and queues
- Storage and data services include S3, EFS, databases, ElastiCache, and DynamoDB
- Delivery and operations include CloudFront, CloudWatch, CloudTrail, Config, disaster recovery, and backup
- It is a roadmap for learning how AWS services fit together, not a prescriptive reference architecture

## Why I saved this
A broad cloud-foundations map that helps place AI workloads inside the networking, compute, storage, and operations systems they depend on.
