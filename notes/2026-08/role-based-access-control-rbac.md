# Role-Based Access Control (RBAC)

![Infographic](/img/notes/2026-08/role-based-access-control-rbac.png)

## Summary
An RBAC slide shows a user assuming a role so that only the role’s permissions are active, isolating task-specific access from the user’s personal grants.

## Key points
- A user with one identity and multiple roles can assume a group or group-membership-backed role for an access context.
- Personal grants are suspended while acting as the role, breaking the permission union and making the active permission set explicit.
- Empty groups can provide exclusive access: users are not members by default and assume the role only when the task requires it.

## Why I saved this
A concise operational pattern for reducing accidental privilege during sensitive work.
