# DuckDB — In-Memory SQL for Analysts

![Infographic](/img/notes/2026-08/duckdb-in-memory-sql-for-analysts.png)

## Summary
A Python developer reference positions DuckDB as an in-memory SQL database for analysts: fast, serverless, and compatible with Pandas and Polars.

## Key points
- DuckDB is described as faster than SQLite for the illustrated analyst use case
- It works with Pandas and Polars dataframes
- It requires no server and can query a dataframe directly with SQL
