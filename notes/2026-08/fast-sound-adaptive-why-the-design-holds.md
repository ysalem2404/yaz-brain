# Fast, Sound, Adaptive — Why the Design Holds

![Infographic](/img/notes/2026-08/fast-sound-adaptive-why-the-design-holds.png)

## Summary
A three-line design claim: the system is fast because its substrate is small, sound because it is symbolic where it must be, and adaptive because it is learned where it should be.

## Key points
- Fast — because the substrate is small.
- Sound — because it is symbolic where it must be.
- Adaptive — because it is learned where it should be.
- The argument is explicitly hybrid: symbolic components carry correctness guarantees, learned components carry flexibility, and each is placed deliberately.

## Why I saved this
A tight articulation of the neuro-symbolic split — a good sentence to reuse when explaining why parts of an agentic system should stay deterministic.
