# Complete AI API Guide for Businesses

![Infographic](/img/notes/2026-08/complete-ai-api-guide-for-businesses.png)

## Summary
A business-oriented API landscape maps hosted model providers, enterprise clouds, local inference servers, search and vector databases, speech, image, and video APIs to common application needs.

## Key points
- Hosted APIs cover customer support, research, multimodal work, and enterprise applications
- Local and self-hosted options include LM Studio, Ollama, vLLM, llama.cpp, and local TTS or speech servers
- Pinecone, Weaviate, Qdrant, and Chroma support semantic search and recommendations
- The map groups providers by task rather than presenting one universal winner

## Why I saved this
A broad discovery map for matching an application requirement to a hosted, enterprise, or local API path.
