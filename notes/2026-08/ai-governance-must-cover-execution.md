# AI Governance Must Cover Execution

![Infographic](/img/notes/2026-08/ai-governance-must-cover-execution.png)

## Summary
The infographic argues that governance cannot stop at model risk, bias, privacy, security, or compliance; it must also govern the execution system where decisions, handoffs, approvals, vendors, data flows, and automated actions create consequences.

## Key points
- The execution layer includes decisions, handoffs, approvals, vendors, data flows, automated decisions, finance, legal exposure, customer experience, and human overrides
- AI creates consequences when it enters execution, not only when it runs inside a model
- An ungoverned execution system scales the underlying governance problem

## Why I saved this
A sharp framing for agent governance: operational controls around actions matter as much as model controls.
