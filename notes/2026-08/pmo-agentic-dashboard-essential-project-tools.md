# PMO Agentic Dashboard — Essential Project Tools

![Infographic](/img/notes/2026-08/pmo-agentic-dashboard-essential-project-tools.png)

## Summary
A PMO dashboard pairs portfolio health, risks, decisions, and agentic results with five essential tools: ChatGPT for orchestration and analysis, Slack for communication, Microsoft Project for planning, Power BI for insights, and Confluence for knowledge.

## Key points
- The dashboard foregrounds portfolio health, project overview, risks, decisions, and agentic results.
- ChatGPT is positioned as an orchestration layer that centralizes information, analyzes scenarios, supports decisions, and orchestrates agents and tools.
- Slack supports real-time communication and alignment; Microsoft Project structures activities and schedules; Power BI provides reports, dashboards, and analytics.
- Confluence captures project knowledge, documentation, lessons learned, and collaboration; the tool alone does not guarantee project success.

## Why I saved this
A practical bridge between agentic tooling and the governance rhythms of a project-management office.
