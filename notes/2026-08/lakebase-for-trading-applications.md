# Lakebase for Trading Applications

![Infographic](/img/notes/2026-08/lakebase-for-trading-applications.png)

## Summary
A Databricks slide describes Lakebase as an option for trading applications, including moving existing applications into Databricks or replacing separate PostgreSQL infrastructure.

## Key points
- The use case focuses on trader-facing applications that need lightweight application infrastructure and operational data access.
- Migration options include moving some existing applications to run inside Databricks or replacing a separate PostgreSQL database with Lakebase.
- The slide presents the choice as a way to consolidate application and data-platform capabilities while supporting new applications.

## Why I saved this
A concrete example of how a data platform may expand into application-serving workloads, beyond analytics and model training.
