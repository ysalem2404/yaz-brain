# Platform Consolidation Outcome — Legacy Stack Replaced by Databricks

![Infographic](/img/notes/2026-08/platform-consolidation-outcome-legacy-stack-replaced-by-databricks.png)

## Summary
A migration outcome slide listing seven distinct legacy tools — SQL Server, SSIS, AWS Lambda, PowerShell, AWS Step Functions, Microsoft Fabric, and Task Scheduler — all collapsed into a single Databricks platform.

## Key points
- Seven separate technologies were retired in favor of one platform.
- The retired set spans three categories at once: databases and ETL (SQL Server, SSIS), compute and glue code (Lambda, PowerShell), and orchestration (Step Functions, Task Scheduler).
- The stack was cross-cloud and cross-vendor, mixing Microsoft and AWS services — consolidation removed the seams between them.
- Microsoft Fabric appears in the replaced column, so this team chose Databricks over Fabric rather than running both.

## Why I saved this
A concrete before-and-after for consolidation arguments, and a data point that Fabric and Databricks were treated as substitutes rather than complements in this case.
