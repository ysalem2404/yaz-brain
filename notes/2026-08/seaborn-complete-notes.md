## Summary
An interview-oriented Seaborn overview explains the library’s relationship to Matplotlib, why it is useful for statistical visualization, how to import it, and the common plot families.

## Key points
- Seaborn is a higher-level statistical visualization library built on Matplotlib
- It works with Pandas dataframes and provides attractive defaults with less code
- Common plots include scatter, line, bar, box, violin, and heatmap charts
- Example use cases include sales dashboards, correlation heatmaps, and distribution graphs
