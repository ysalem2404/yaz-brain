# 9 Python Libraries Every Data Analyst Should Know

![Infographic](/img/notes/2026-08/9-python-libraries-every-data-analyst-should-know.png)

## Summary
A practical map of nine Python libraries spanning data wrangling, numerical computing, visualization, statistical modeling, machine learning, database access, and interactive dashboards.

## Key points
- Pandas and NumPy cover tabular manipulation and vectorized numerical work
- Matplotlib, Seaborn, and Plotly cover static, statistical, and interactive visualization
- Scikit-learn and Statsmodels support prediction, clustering, hypothesis testing, and inference
- SQLAlchemy connects Python analysis to SQL databases
