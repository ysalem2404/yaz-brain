# Supervisor v1 Failed Fast — Building Agent Foundations

![Infographic](/img/notes/2026-08/supervisor-v1-failed-fast-building-agent-foundations.png)

## Summary
A retrospective traces an agent platform from a failed Supervisor v1 through DSPy routing, SmolAgents, GPU graph work, refactoring, Magneto-Core, and a later V5 Supervisor, arguing that early failure helped build durable foundations.

## Key points
- Supervisor v1 exposed a routing bottleneck and a need for more deliberate architecture.
- Later iterations explored DSPy routing, SmolAgents, GPU graphs, refactoring, and a V5 Supervisor with planning and reflection.
- The industry timeline moves from monolithic agents and basic chains toward modular graph patterns, Graph RAG, semantic tools, and supervisor-plus-reflection designs.
- The central lesson is to implement and test agent foundations early rather than only architecting them.
