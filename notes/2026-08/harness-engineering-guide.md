# Harness Engineering Guide

![Infographic](/img/notes/2026-08/harness-engineering-guide.png)

## Summary
A system diagram for harness engineering surrounds LLMs with guardrails, evaluation, orchestration, monitoring, optimization, and a feedback loop to produce reliable outputs.

## Key points
- Inputs include data sources, APIs and tools, user input, and business rules
- The harness layer combines policies, filters, guardrails, safety, evaluation, testing, and orchestration around one or more LLMs
- Monitoring, optimization, and a context layer feed a Measure → Learn → Improve feedback loop

## Why I saved this
A strong visual checklist for treating the surrounding system—not only the model—as the reliability surface.
