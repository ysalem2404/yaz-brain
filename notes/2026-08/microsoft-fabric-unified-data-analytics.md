# Microsoft Fabric: Unified Data Analytics

![Infographic](public/img/notes/2026-08/microsoft-fabric-unified-data-analytics.png)

## Summary
A Microsoft Fabric explainer presents the platform as an end-to-end SaaS data environment combining ingestion, storage, engineering, data science, real-time analytics, and business intelligence.

## Key points
- OneLake provides a unified data lake intended to reduce silos and duplication
- Fabric combines Data Factory for ETL, data engineering with Spark, data science and AI, real-time analytics, and Power BI
- Copilot and natural-language capabilities are embedded across the platform, while streaming analytics supports monitoring systems and applications
- The value proposition is a single environment for data lifecycle work rather than a collection of disconnected tools

## Why I saved this
A useful map of Microsoft’s integrated data-and-AI platform and the layers that sit between raw data and business decisions.
