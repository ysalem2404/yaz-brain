# Microsoft Copilot Ecosystem

![Infographic](/img/notes/2026-08/microsoft-copilot-ecosystem.png)

## Summary
A Microsoft ecosystem map connects Copilot experiences across Microsoft 365, Power Platform, Fabric, security, Dynamics 365, Azure AI, GitHub, Windows, and developer tooling.

## Key points
- Microsoft 365 Copilot is shown alongside Word, Teams, PowerPoint, Excel, Outlook, OneDrive, SharePoint, and Windows
- The platform foundation includes Microsoft Fabric, OneLake, Entra ID, Azure OpenAI Service, Azure AI Foundry, and Azure Machine Learning
- Business and developer surfaces include Dynamics 365, GitHub Copilot, Visual Studio Code, Azure DevOps, Copilot Studio, and Power Automate
