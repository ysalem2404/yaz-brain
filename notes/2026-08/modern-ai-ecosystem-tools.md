# The Modern AI Ecosystem — Tools

![Infographic](/img/notes/2026-08/modern-ai-ecosystem-tools.png)

## Summary
A broad ecosystem map groups modern AI tools across models and runtimes, agent frameworks, RAG and data tooling, embeddings, MCP, security, memory, automation, and vector databases.

## Key points
- Model and runtime options include OpenAI GPT, Anthropic Claude, Google Gemini, Meta Llama, Mistral, Cohere, Hugging Face, Ollama, and vLLM.
- Agent and workflow frameworks include CrewAI, LangGraph, AutoGen, Microsoft Agent Framework, LlamaIndex, AWS Strands, CAMEL, and LangChain.
- RAG and data tooling spans Haystack, DSPy, RAGFlow, GraphRAG, Unstructured, EmbedChain, and vector or embedding providers.
- MCP connects assistants to services such as GitHub, Slack, PostgreSQL, Google Drive, and filesystem servers; security and memory form adjacent layers.
