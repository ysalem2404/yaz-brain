# Chaining AI Functions

![Infographic](/img/notes/2026-08/chaining-ai-functions.png)

## Summary
A Databricks slide shows AI functions chaining directly from ai_parse_document output to support document Q&A, structured extraction, and semantic search or RAG workflows.

## Key points
- ai_query supports questions and reasoning over parsed content with an LLM.
- ai_extract pulls structured entities, key-value pairs, or specific data points from the parsed layout.
- Semantic search and RAG functions build search across documents for downstream workflows.
- The chaining pattern turns parsed documents into composable building blocks for more complex workflows.
