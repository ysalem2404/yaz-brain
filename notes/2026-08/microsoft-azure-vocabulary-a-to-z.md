## Summary
An A-to-Z reference maps Azure services to concise jobs across hybrid management, storage, databases, data pipelines, event streaming, serverless, AI, networking, security, and DevOps.

## Key points
- The map spans core services such as Azure Arc, Blob Storage, Cosmos DB, Data Factory, Event Hubs, Functions, and Virtual Machines
- AI and analytics entries include Azure OpenAI Service, Azure AI Foundry, Azure Machine Learning, Microsoft Fabric, and HDInsight
- Networking, identity, secrets, queues, monitoring, and deployment services round out the platform vocabulary
