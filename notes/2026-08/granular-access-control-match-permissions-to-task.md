# Granular Access Control — Match Permissions to the Task

![Infographic](/img/notes/2026-08/granular-access-control-match-permissions-to-task.png)

## Summary
A security guidance slide argues that permissions should be narrowly matched to each task, with policy-driven repetition, attribute-based rules where conditions repeat, and role-based rules where access should not remain active all at once.

## Key points
- Grant only the permissions required for the task rather than broad standing access.
- Use policy-driven rules for repeated decisions and attribute-based access control when the same rule applies across many objects.
- Use role-based access control when permissions should not be active for every task; attributes can change access decisions.
- Control who can set, update, and use access attributes, and review complex authorization over time.
